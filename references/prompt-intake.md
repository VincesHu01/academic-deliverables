# 接单澄清清单

需求常由**角色、背景素材和编号要求**组成。信息不完整时，用下面的清单一次性补齐。

## 必问（5 项）

1. **交付物形态**：可编辑 .pptx / .docx，还是只要文字内容？（默认给可编辑源文件）
2. **受众与调性**：纯学术 / 政府汇报 / 展示竞选 / 课程作业
3. **体量**：页数、字数或时长上限
4. **配色**：不指定则用默认基线（学术=白+绿；政府=黑+红）
5. **是否配讲稿**：需要的话确认时长（3 分钟≈800 字，5 分钟≈1300 字）

## 场景化追问

### PPT
- 页数上限？必须包含封面/目录/结语吗？
- 有没有指定的分析框架、理论或参考材料需要严格遵循？
- 需不需要配图 / 能否联网搜高清图 / 是否有用户素材必须使用
- 有没有禁止引入的学者观点

### Word
- 是否需要遵循已有文档或模板的体例
- 字数要求精确到什么程度
- 是否需要公式（要的话必须 OMML 对象）
- 是否需要三线表 / 代码 / 原始输出截图
- 产物输出目录与命名规范

### 读后感 / 课程感悟 / 读书报告（按 `reflection-spec.md` 执行）
- **哪一讲 / 哪本书 / 哪次汇报**，以及是单讲还是多讲合辑（决定骨架 A/B/C/D）
- **素材来源**：课程笔记、讲义原文、老师原话、听课时记下的疑问——没有原文时先索取，禁止凭空转述
- **字数区间**（单讲 900–1500 字，多讲合辑 1500–3000 字）
- **要"我"到什么程度**：只写学术反思，还是允许写入自己的旧经历与具体事件（默认允许且必须具体）
- **是否叠加个人文风 skill**：如有自己的风格指纹 skill，按 `reflection-spec.md` 第十二节做 voice overlay
- **真实性红线**：不得编造未发生的课堂细节、老师原话、书目页码（见该文件第十三节）

## 常见需求信号

出现以下表述时，应严格按编号要求逐条落实：

- "你是一个资深的……教授 / 基层工作人员 / 策划者……"
- "以下为具体的要求，必须要严格遵循："
- "最后强调，请严格遵守这 N 条规则"
- "要求：1、…… 2、…… 3、……"

出现以下表述时，视为**修改轮**，只改点名部分，不要顺手优化别处：

- "现在还有几个问题，需要你帮忙修改："
- "继续重做。现在的问题是："
- "其他内容不要动"
- "还是有几个问题需要修改："
