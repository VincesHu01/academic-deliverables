# 去 AI 味清单

交付前逐条检查，避免套话、模板化结构和缺乏证据的表述。

## 一、句式黑名单

出现即改：

| AI 味 | 替换方向 |
| --- | --- |
| 综上所述 / 总而言之 | 直接给判断，或删 |
| 随着……的不断发展 / 在当今时代背景下 | 直接说事实 |
| 具有重要的意义 / 发挥着重要作用 | 说清"对谁、在哪一步、有多大" |
| 值得注意的是 / 不难发现 / 由此可见 | 删，或换成具体推论 |
| 首先……其次……最后……（无实质递进） | 改成因果/转折/让步的真实逻辑 |
| 不仅……而且……（强行对仗） | 拆成两句 |
| 为……提供了有力支撑 / 奠定了坚实基础 | 说清支撑了哪个具体环节 |
| 赋能 / 抓手 / 闭环 / 生态（滥用） | 换成具体动作 |
| "本文从 X、Y、Z 三个方面展开" | 直接展开 |
| 每段都以"从……角度来看"开头 | 换开头 |

## 二、结构层面的 AI 痕迹

- ❌ 三段式排比（凡事必凑三点）
- ❌ 每段长度几乎相同
- ❌ 每段都是"总—分—总"
- ❌ 破折号密集（每页/每段超过 1 个）
- ❌ 全篇没有一句带主观判断的话
- ❌ 通篇无数据、无年份、无人名
- ❌ 形容词密度过高（"深度、全面、系统、多维"）

## 三、正面要求：什么才像人写的

- **有具体性**：年份、数字、人名、地名、文件名、参数值
- **有判断**：不只是"A 认为 X，B 认为 Y"，还要"我认为……因为……"
- **有保留**：承认边界、反例和数据局限，不对证据不足的问题作强因果推断
- **有节奏**：长短句交替，必要时用短句明确判断
- **场景适配**：讲座笔记等口语场景可保留适量自然口语，正式文本保持简洁
- **术语精准**：用学科内真实术语，不用泛化的大模型腔

## 四、学术场景额外检查

- [ ] 每条参考文献可溯源（作者/题名/期刊/年份四要素齐全）
- [ ] 无学位论文、新闻、公众号、百科类引用
- [ ] 引用格式为"作者（年代）"，无"某学者认为"
- [ ] 有文献对话，不是文献罗列
- [ ] 明确区分"现实问题"与"学术问题"
- [ ] 结论降调，无过度因果断言
- [ ] 图表与正文相互指涉（正文说了图说明了什么）
- [ ] 数据来源、口径、清洗规则有说明

## 五、PPT 场景额外检查

- [ ] 无"谢谢观看""汇报时长 X 分钟"等页脚废话
- [ ] 无装饰性无信息量的英文副标题
- [ ] 每页一个论点，页间有递进
- [ ] 视觉主体承载信息，不是装饰
- [ ] 字号全部达标
- [ ] 配色 ≤ 2 个色相
