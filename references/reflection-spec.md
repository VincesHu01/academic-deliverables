# 读后感 / 课程感悟 / 读书报告 专项规范

> **定位**：`word-spec.md` 管**排版形态**（字体、行距、三线表、OMML 公式），本文件管**语言与思维方式**。
> 两者必须同时加载。读后感类交付物最常见的失败不是排版，而是「写成课程笔记」「写成检讨书」「写成 AI 总结」。

**触发词**：读后感、读书报告、读书笔记、课程感悟、讲座心得、研修反思、观后感、学习体会、汇报感悟、结课总结。

## 零、三条硬性交付指标

| 指标 | 要求 | 违反后果 |
| --- | --- | --- |
| 段落结构 | 每个自然段走完「五步单元」，顺序不可乱 | 缺第⑤步即退化为读书笔记 |
| 内容配比 | 课程/书中内容转述 55–65%，自我经历与反思 35–45% | 分段割裂成「课程讲了 X。我学到了 X。」即失败 |
| 具体物 | 每段至少 1 处：地名、人数、金额、时间、原话、案例细节 | 抽象判断堆叠，读起来像 AI 总结 |

## 一、五步单元（最小不可再分结构）

我的（也是本规范要求的）每一个自然段都跑完这五步，**顺序基本固定，不能乱**：

| 步 | 作用 | 典型写法 | 篇幅 |
| --- | --- | --- | --- |
| ① 旧认知锚 | 交代「我」之前怎么想，且这个想法通常是**错的、浅的、功利的** | 之前，我一直认为…… / 以往我做研究非常喜欢…… | 1–2 句 |
| ② 触发事件 | 老师一句话 / 书里一个案例 / 一个具体场景 | 但课堂上老师反复提出的…… / 书中以……的案例揭示…… | 1–2 句 |
| ③ 认知断裂 | 明确标记「我错了」 | 这让我反思…… / 现在想来…… / 听完后我是有点尴尬的 | 半句 |
| ④ 新命题 | 把触发事件抽象成一个可复述的学术判断 | 真正的研究问题有其规范路径：…… / 这说明，…… | 2–3 句 |
| ⑤ 回扣自身 | 落到「我」的具体经历或今后怎么做 | 我的本科毕业论文是定量研究，但我对二手数据没有核验真伪 / 以后调研务必要…… | 1–2 句 |

**关键**：① 和 ⑤ 必须都是第一人称的**具体事**，不能是泛泛的「我认识到……」。④ 与 ⑤ 之间常插一句自我批评（「这其实是不严谨的」）。

## 二、三件套规则

一个认知转折点 = **金句 + 案例/数字 + 我的旧经历**，缺一不可。

> 例（示意）：转折点「减贫的关键不是缺钱，而是缺权」
> - 金句：「富饶的贫困」
> - 案例：某梯田景区门票几十元，扛专业相机的游客上百人，而参与耕作的村民依旧贫困；村里老人第一次分红拿到一千多元
> - 旧经历：我过去游览古村落的第一反应是「好美好出片」，从不追问原住民得到了什么

一篇文章**只写 2–3 个转折点**。没有落差的知识点不写。

## 三、整篇骨架

### A. 单讲 / 单篇感悟（900–1500 字）

```
标题：第X讲 主题（可加一个副主题，中间用空格隔开）

[段1 入场]  这个主题在我原认知里的样子 + 当时情绪（轻视 / 期待 / 怀疑 / 焦虑）
[段2 转折一] 五步单元
[段3 延伸]   对新命题的保留、边界或反向追问（「同时我也认为……」「或许……」）
[段4 转折二] 五步单元（换一个子话题）
[段5 细节]   本讲最打动我的一个具体画面 / 数字（单独成段，慢下来）
[段6 认错]   我过去做过的一件敷衍事，具体到地点与做法
[段7 收束]   总而言之 → 作为……的学生，最需要的不是 X，而是 Y
```

### B. 多讲合辑（如「课程总结」）

每讲按 A 执行；各讲之间**不写过渡段**，直接换标题行。开头不加总述，结尾不加总结。

### C. 课堂汇报 / 同学互评感悟

```
[段1] 同学们选题列举（3–4 个具体题目）
[段2] 共性诊断：大家都在找新现象，却把「新瓶装老酒」当成创新 → 我的新认知
[段3] 点评规律：反复追问「条件」「边界」「对象是谁」「在什么情境下成立」 → 收敛到「小切口」
[段4] 表达精确性：题目看不懂会被直接拒、词语用错场合被指出 → 对写作的要求
[段5] 互评的价值：老师的点评自上而下指方向，同学的追问平视、照见细微断裂
[段6] 我的研究被指出什么不足 + 下一步要纳入哪些变量（写成机制清单）
```

### D. 读书报告 / 文献反思

把「老师」替换成「作者 / 书中」，触发事件改为书中某章某例，其余与 A 完全一致。读书报告的独特要求：**必须交代这本书在自己的问题谱系里解决了什么、又留下了什么**，不能只写「这本书讲了什么」。

## 四、段落内部句序（可直接套）

```
句1（旧认知，带时间标记：之前／以往／过去／本科时）
句2（触发：老师提出的……／书中指出……／老师讲到的……故事）
句3（断裂 + 新命题，用「但／然而／这让我反思」起）
句4（展开新命题，用「这说明……」「究其原因……」「进一步地……」）
句5（具体证据：案例 / 数字 / 原话）
句6（回扣自身：我……／以后……／这也引发了我的一些思考）
```

段落长度 **250–450 字，4–6 句**，段内不设小标题。

## 五、句式库（按功能分类，直接套用）

### 5.1 起手：旧认知
- 之前，我一直认为……；加之……，我始终难以感受到其中的价值所在。
- 以往我做研究非常喜欢……，认为这种……最为可靠。
- 上课之初，我甚至在和室友感慨，说从未听说……还有学科史。
- 过去……时，我的第一反应往往是……，却很少追问……。

### 5.2 触发
- 老师提出的「……」，缓解了我的一些学术焦虑。
- 书中指出，……
- 老师讲到的……故事，给我留下了深刻的印象。
- 联想我过去……的经历，……

### 5.3 断裂与反思
- 这让我反思……；由此我明白……；现在想来，……
- 听完老师讲述后，我是有点尴尬的。
- 这堂课让功利前行的我及时驻足，重新审视……

### 5.4 区分与界定（**最高频、最标志性的句型**）
- X 只是……并非……（某类现象只是泛泛的研究领域，并非具体的研究问题）
- X 不等于 Y（新奇的案例、复杂的研究方法不等于学术价值）
- 这并非是……而是……（这并非是……素质差，而是利益分配机制缺失所引发的矛盾）
- 看似……实则……（看似是顺带游玩，实则是一种带着问题深入田野的知识生产）
- 一味……只会……（一味追求形式创新、标榜西方理论，只会陷入学术上的功利主义）
- 不能只……而应……（不能只关注眼前美丽的风景，而应主动去思考住在这儿的人过得怎么样）
- 不是……而是……（不是让所有人消费得更昂贵，而是让每一笔消费都聚焦在真实的体验上）

### 5.5 设问自答
- 高价是否就等同于消费升级？……其实不然。
- 但是，X 是否就等同于 Y？我认为评判……不能只看……，还需要厘清……
- 「物有所值」真的一定成立吗？

### 5.6 反事实与限定
- 如若……无法保证，最终得到的恐怕是一个「精确的错误结论」。
- 一旦……退出，这套规则能否持续运转仍是有待追踪的学术命题。
- 哪怕像……这样完善的模式也不一定具有普适性。
- 进一步地，……（高频连接词）

### 5.7 三连问 / 三连列收尾
- 谁在受益、谁在被边缘化、谁在被忽视？
- 厘清模糊的关系、界定理论边界、补齐缺失的机制（三连动宾）

### 5.8 保留与质疑（学者语气）
- 同时我也认为这是一种学术的建构，如果学者只聚焦……，那么……很容易会被宏大叙事所蒙蔽。
- 相较而言，特定时代的非主流研究，或许会隐藏更多新颖的学术价值。
- 这仍是有待追踪的学术命题。

### 5.9 自我批评（**必须有，且要具体**）
- 本科时我参与过多次乡村调研，却只是发问卷、录入数据后草草完成任务。
- 我的本科毕业论文是定量研究，但我对所拿到的二手数据没有核验真伪，这其实是不严谨的。
- 以前，我很喜欢复杂的模型与海量的数据，认为研究的「高级」就等同于研究的「优秀」。

### 5.10 结尾
- 总而言之，这节课给我的最大启发是：……，而不是……
- 作为刚读研一的学生，我觉得自己最需要的不是学会多少高级的论文研究方法，而是建立这种「从真问题出发」的自觉，以及敢于走到田野里去的勇气。
- 这也是未来从事学术研究必备的核心素养。

## 六、词汇、术语与标点

### 6.1 高频连接词（语言指纹）
进一步地、此外、同时我也在思考、由此、由此明白、这也引发了我的一些思考、现在想来、以前/以往/过去 → 但现在、总而言之。

### 6.2 认知动词
让我明白、让我意识到、让我读懂、让我重新理解、刷新了我的认知、改变了我很多想法。

### 6.3 判断限定
真正的、并非、实则、看似、恰恰、或许、可能、有待追踪、某种意义上、一定程度上。

### 6.4 慎用词（出现就要紧跟具体物）
「显著」「大幅」「极大地」「深刻」「重要意义」「核心价值」——这类词只在后面紧跟具体数字或场景时才用。

### 6.5 术语必须配解释或场景，不能裸用
- ✅ 正确：把术语落在一个能看见的场景上（如权益分配机制 + 分红细节）
- ❌ 错误：这体现了 X 理论与 Y 增权的重要性。

### 6.6 标点与节奏
- **长句为主**，一句话常含 3–4 个逗号分句，靠语义推进而非连接词堆叠。
- **几乎不用感叹号**（全文 ≤1 个，且只在引述他人情绪时）。
- **分号**用于并列两个独立论断；**破折号**用于插入同位解释；**顿号**用于名词堆叠；**引号**专用于被引金句、被反思的俗见、自造的反讽概念。
- 偶尔**破长句为短句**强化判断：「其实不然。」「……但不是唯一标准。」
- **全文不用 emoji、不用加粗堆砌、不用列表切碎段落**（列表只用于真正的清单）。

### 6.7 情绪曲线
克制、不煽情、不励志。允许暴露焦虑、尴尬、功利、自我怀疑。**禁止**：热血、感恩、煽情、「在老师的悉心教导下」。

## 七、禁用词清单

### 7.1 绝对禁用（出现即判不合格）

| 类别 | 禁用词 |
| --- | --- |
| 空评价 | 受益匪浅、干货满满、深入浅出、娓娓道来、令人深思、意犹未尽、醍醐灌顶、豁然开朗、精彩纷呈、发人深省 |
| 空收获 | 我收获很大、学到了很多、对我帮助很大、开阔了眼界、提升了认知、拓宽了视野、收获颇丰 |
| 客套 | 在老师的悉心教导下、感谢老师的辛勤付出、这门课让我成长了许多 |
| AI 连接 | 首先/其次/再次/最后（机械四段）、值得注意的是、综上所述、不难看出 |
| 煽情 | 深深地、极大地、无比、令人动容、热泪盈眶、心潮澎湃 |
| 格式 | emoji、段内加粗堆砌、无意义的列表、小标题切碎段落 |
| 标点 | 感叹号（全文 ≤1 个） |

> 「首先」可用，但后面必须接「进一步地／此外／同时我也在思考」，**不能接「其次/再次/最后」**。

### 7.2 相对禁用（用则必须紧跟具体物）

显著提升、大幅优化、非常重要、核心价值、深刻影响、重要意义、极大促进。
→ 要么换成具体数字（「从 3 个村扩展到 47 个自然村」），要么换成弱限定（「一定程度上」「或许」）。

## 八、八股文 vs 合格文风：对照改写

**① 空评式**
- ❌ 老师的这堂课深入浅出，让我受益匪浅，对旅游研究有了更深刻的认识。
- ✅ 这堂课让功利前行的我及时驻足，重新审视这个专业与学术研究的真正内核；老师提出的「Research is Discovering」，缓解了我的一些学术焦虑。

**② 复述式（没有「我」）**
- ❌ 本节课老师讲解了旅游吸引物权的概念，并以某案例说明了分红机制的运行方式。
- ✅ 「社区参与」「旅游增权」在文献里出现得太频繁，以至我几乎不再去想它背后是一个个具体的人；听完课后，这些词第一次有了重量。

**③ 方法崇拜式**
- ❌ 我学会了要用更科学的研究方法，避免主观偏差。
- ✅ 以前，我很喜欢复杂的模型与海量的数据，认为研究的「高级」就等同于研究的「优秀」。然而，数据和样本皆有原生的背景，如若真实性、代表性无法保证，最终得到的恐怕是一个「精确的错误结论」。

**④ 升华式空话**
- ❌ 未来我将努力钻研，为学科发展贡献自己的力量。
- ✅ 作为刚读研一的学生，我觉得自己最需要的不是学会多少高级的论文研究方法，而是建立这种「从真问题出发」的自觉。

**⑤ 全盘接受式**
- ❌ 老师的分期框架准确地概括了三十年发展历程，我完全认同。
- ✅ 同时我也认为这是一种学术的建构，如果学者只聚焦单一的分期框架、忽视多元交错的研究脉络，那么跨阶段的边缘研究很容易被宏大叙事所蒙蔽。

**⑥ 抽象总结式**
- ❌ 总之，研究要兼顾理论与实践，二者缺一不可。
- ✅ 总而言之，这节课给我的最大启发是：不要着急找方法套框架，而是先想清楚我要关注的是什么问题，以及问题背后发生了什么。

**⑦ 通用排比式**
- ❌ 是理念的更新，是方法的革新，更是视野的开拓。
- ✅ 一个优秀的学者，不是靠聪明和捷径，而是靠一遍一遍地在理论和实践之间调整深耕，靠在一个地方扎得足够深。

## 十、常见失真点与修正

| 失真现象 | 原因 | 修正 |
| --- | --- | --- |
| 写成课程笔记 | 只有转述没有「我」 | 每个观点后补一句「我以前……」「以后……」 |
| 写成检讨书 | 只有认错没有学科内容 | 认错必须挂在一个学术判断上（数据未核验 → 数据有原生背景） |
| 太像论文 | 术语密集、句子短促 | 拉长句子，插入具体场景，把术语放到引号或解释里 |
| 太像公众号 | 金句堆砌、情绪上扬 | 删掉所有「惊艳」「震撼」，改用数字与动作 |
| 结尾喊口号 | 「为……贡献力量」 | 改成「最需要的不是……而是……」＋一条可执行的纪律 |
| 段落一样长 | 节奏单调 | 允许 1 段短句强调（「其实不然。」），允许一段长句铺陈 |
| 全篇无落差 | 每个知识点都被接受 | 删掉没有「我以前以为是 A，其实是 B」的知识点 |

## 十一、长度控制

| 类型 | 字数 | 段数 |
| --- | --- | --- |
| 单讲感悟 | 900–1500 | 5–7 |
| 多讲合辑 | 每讲 1000–1400 | 每讲 5–7 |
| 汇报感悟 | 800–1200 | 4–6 |
| 读书报告 | 1200–2000 | 5–8 |

超长时**砍知识点，不砍细节**——宁可少写一个转折点，也不能把案例和数字抽象化。
用户给出精确字数时按 `word-spec.md` 第八节执行（「左右」= ±10%；精确上限卡死，宁少勿多）。

## 十二、与个人文风 skill 叠加（voice overlay）

本文件提供的是**可移植的通用工艺**：结构、配比、句式功能分类、禁用词、自检。
若使用者另有个人文风 skill（例如 WorkBuddy 里按本人真实成稿归纳的私人 voice skill，内含个人句式库存、真实经历范本、个人词表与打分表），按下面的方式叠加：

```
        → word-spec.md（排版形态）
        → anti-ai-checklist.md（去 AI 味复核）
```

**冲突裁决**：
1. 个人 voice skill 的句式库、词表、范本**优先**于本文第五、六节的通用句式库。
2. 第零节的**三条硬性指标**与第七节的**禁用词清单**不可被个人风格覆盖——它们是质量的底线，不是偏好。
3. 个人 voice skill 提供的真实经历、私人范本、身份信息只用于素材层，**不得写进公开交付物或本仓库文件**。

## 十三、隐私与真实性红线

- 不得在产出或说明中推断、补充或暴露使用者的真实身份、机构、师承、研究方向、未公开的调研地点与个人经历。
- 材料不全时，用**标注为推断**的方式补齐（如「此处为推断」），不空等，但也不能把推断写成事实。
- 不伪造引用、不冒充他人原话；金句须可溯源，无法溯源时写明「大意是」。
- 示意性案例（第六节、第八节中的 ✅ 例子）仅用于说明写法，**不是真实引用**，交付时不得直接搬运为文内证据。
