# PPT 规格基线

以下条目是可复用的 PPT 制作与验收基线；若用户提供模板或品牌规范，以当前任务要求为准。

## 一、风格四选一（必须先确认）

| 场景 | 调性 | 主色 | 每页文字量 |
| --- | --- | --- | --- |
| **纯学术**（课程汇报/组会/答辩） | 学术严谨、克制 | 白 + 单一绿（或深蓝） | 中等，观点可直接呈现 |
| **政府汇报** | 公文式、正式 | 黑 + 红（含浓淡） | 偏多，"大部分观点要直接呈现在 ppt 上" |
| **竞选/展示** | 高级质感、整齐、易读 | 深色 + 单一强调色 | 少而精，靠图说话 |
| **作业 PPT** | 简洁、不要过多页 | 黑白灰 | 精简，"不要特别多没用的文字补充" |

> 学术场景默认克制、低饱和；正式汇报可使用黑、白、红及其明度变化。

## 二、配色硬约束

- **色相总数 ≤ 2**（含主色的浓淡变体不算新色相）
- 默认学术基线：
  - 背景 `#FFFFFF`
  - 主色 `#1F6B4F`（深绿）或 `#14532D`
  - 辅色 `#E8F1EC`（主色 10% 淡）
  - 正文 `#1A1A1A`，次要文字 `#5A5A5A`
  - 强调/警示 `#B3202C`（仅用于关键结论、否定项）
- 禁止：渐变炫彩、多色图标堆砌、每张页换配色、深色背景配亮色荧光字
- 图表颜色只允许黑 / 白 / 灰 / 主色（政府汇报场景加红）

## 三、字体与字号

- **字体仅允许两种**：正文 / 标题统一用**微软雅黑**（Microsoft YaHei）；注释 / 图注 / 表注用**楷体**。禁止混用其他字体族。
- **正文不得过小**。字号下限如下表：

| 元素 | 16:9（13.333×7.5in） |
| --- | --- |
| 页面标题 | ≥ 28pt |
| 一级正文 | ≥ 18pt |
| 二级正文 / 图表标签 | ≥ 14pt |
| 图注 / 数据来源 / 注释 | ≥ 10pt（下限，绝不低于 10pt） |

`check_pptx.py` 会把 <10pt 的文字直接判为失败。

## 四、结构要求

- **页数**：默认 ≤ 15 页；用户给出上限时严格遵守
- **常用结构**：封面 → 目录 → 正文 → 结语；短文稿可按任务需要精简
- **每页一个论点**：每页应有清晰边界和主讲内容
- **必须有过渡**：页与页之间要有递进、转折或承接，不能只是并列罗列
- **视觉节奏**：连续 3 页纯文字 = 不合格；连续 5 页都是同一种图表 = 不合格

## 五、每页的视觉主体（红线 B 的具体化）

每页恰好一个视觉主体，从下列选一，且必须承载论点：

1. **路径图 / 流程图** — 用于"机制""演进""从现实问题到学术问题"
2. **示意图 / 框架图** — 用于"分析框架""三个层次"
3. **三线表** — 用于数据结果、政策梳理对照
4. **对比色块** — 用于正反面、国内外、前后对比
5. **单张高清配图** — 用于场景说明（政府汇报、竞选展示）

判断它是不是装饰：**删掉它，这页还剩多少信息？** 剩余完整 = 装饰，删。

## 六、禁止出现的内容

禁列表：
- ❌ 页脚写"汇报时长 X 分钟""感谢聆听""谢谢观看"
- ❌ 每页重复的水印式副标题、无信息量的装饰性英文
- ❌ 无关的页眉页脚、日期、版本号
- ❌ 占位符文字、Lorem ipsum、示例数据
- ❌ AI 味套话："综上所述""在当今时代背景下""随着……的不断发展""具有重要意义"

## 七、配图规则

- 高清，不重复使用（"照片不得重复使用"）
- 用户明确要求保留的文字和图片**必须全部用上**
- 截图类素材（微信/QQ对话、数据界面）必须保证文字可辨认，必要时放大加粗
- 图表背景统一白色；字体优先与正文一致，若专业图表工具有成熟默认样式可沿用

## 八、讲稿配套

| 时长 | 参考字数 |
| --- | --- |
| 3 分钟 | 750–850 字 |
| 5 分钟 | 1250–1400 字 |

- 讲稿与 PPT 逐页对应，标注页码
- 用户给出精确上限时必须严格控制，宁少勿超
- 讲稿口语化但保留学术内核，不要照读 PPT 上的字

## 九、可编辑性

- 交付 `.pptx`，不要 PDF / 图片 / 只想给我看效果
- 文字必须是真文本框（`check_pptx.py` 会检查是否有文本框架）
- 图表尽量用原生形状或表格绘制，不要整体贴成图片；仅在用户明确只需预览效果时例外
