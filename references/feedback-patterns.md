# 常见返工模式与预防规则

生成内容后，用本表检查容易引发返工的问题。这里只保留可复用的 PPT/Word 制作要求，不记录个人背景或历史原话。

## A. 视觉与风格

| 问题 | 预防规则 |
| --- | --- |
| 配色过杂、模板感强 | 默认 1 个主色加黑白灰；必要时增加 1 个强调色 |
| 页面只有要点文字 | 每页设置一个承载论点的视觉主体 |
| 色块、流程图和图标过多 | 每页最多一个主要视觉结构，删除不承载信息的装饰 |
| 字号偏小 | 正文建议 ≥18pt，注释不得低于 10pt |
| 页面拥挤 | 每页聚焦一个论点，并保留足够留白 |
| 风格与场景不符 | 根据学术汇报、正式汇报、展示或作业选择调性；不确定时先确认 |

## B. 内容与深度

| 问题 | 预防规则 |
| --- | --- |
| 分析停留在表面 | 每个结论同时回答“是什么、为什么、证据是什么” |
| 缺少理论或依据 | 使用任务指定或经核验的分析框架，并标明来源 |
| 章节断裂 | 章末收束、章首承接，明确递进或转折关系 |
| 标题空泛 | 标题直接表达本页或本章的具体判断 |
| 文献堆叠 | 呈现观点之间的支持、补充或分歧，并给出综合判断 |
| 图表与正文脱节 | 正文解释图表说明了什么，以及它支持哪个后续论点 |
| 内容过简或过长 | 遵守页数、字数和时长上限；术语首次出现时给出必要解释 |
| 修改变成全盘重写 | 先列保留项与修改项，只改动问题范围 |
| 擅自删除素材 | 删除前说明原因并获得用户同意 |

## C. 格式与交付

| 问题 | 预防规则 |
| --- | --- |
| 只交图片或 PDF | 交付原生可编辑的 `.pptx` 或 `.docx` |
| 结果散乱 | 数据和对比结果优先使用结构化表格 |
| 跨页导致上下文断裂 | 同一题或同一结果块尽量保持在一起 |
| 原始输出样式混乱 | 统一块样式、标题和命名 |
| 代码不可运行 | 实际运行验证，并说明依赖、输入和顺序 |
| 无法复现 | 随交付提供必要的复现说明与来源信息 |

## D. 学术诚信与隐私

| 问题 | 预防规则 |
| --- | --- |
| 文献或数据来源不实 | 核验作者、题名、来源、年份与数据出处；不确定时不引用 |
| 无名归因 | 禁止“某学者认为”等无法追溯的表述 |
| 结论过度绝对 | 说明证据边界，避免证据不足的强因果断言 |
| 泄露用户身份线索 | 不推断或写入个人背景、研究方向、机构、团队、常用人物或著作 |

## E. 修改轮处理

- 用户用编号提出问题时，回复也按编号逐项对应。
- 用户要求“其他内容不要动”时，只修改点名部分。
- 用户明确要求重做时，不用局部微调冒充重做。
